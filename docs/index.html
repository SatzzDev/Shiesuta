Features

Everything you need

Built for a great music experience on Discord — powerful, fast, and easy to use.

🎵

High-Quality Playback

Crystal-clear audio via Lavalink v4 with full voice channel support and volume controls.

🔍

Universal Search

Play directly from YouTube, Spotify, SoundCloud, and more — just paste a URL or query.

📋

Queue Management

Full queue system with pagination, now-playing, and real-time lyrics display.

🔀

Loop & Shuffle

Repeat a single track, the whole queue, or disable — and shuffle your queue on the fly.

🌍

Multi-Language

Built-in i18n for English, Indonesian, and Malay. Switch with a simple command.

⚡

Lightweight & Fast

Built for Bun and Node.js — minimal footprint, optimized for VPS or 24/7 hosting.

Commands

Simple & intuitive

All commands use the . prefix by default.

.play Play a song or playlist by query or URL.
.skip Skip the current track and play the next.
.pause Pause the current playback.
.resume Resume playback after pausing.
.stop Stop playback and destroy the player.
.loop Cycle loop mode: track, queue, none.
.shuffle Shuffle the current queue.
.queue View the queue with pagination.
.set lang Change bot language: en, id, or ms.
.help Show all available commands.
Setup

Quick Setup

Up and running in under 5 minutes.

  • Clone & Install

    git clone https://github.com/KurniawanSatria/Shiesuta.git
    cd Shiesuta
    bun install

  • Configure

    cp config.json.example config.json
    # Edit config.json with your bot token,
    # Lavalink node, and Spotify keys.

  • Run a Lavalink server

    Shiesuta requires a running Lavalink v4 server. Make sure the URL, port, auth, and secure settings in config.json match.

  • Start the bot

    bun start
Enable the Guilds, Guild Voice States, Guild Messages, and Message Content intents in the Discord Developer Portal.
